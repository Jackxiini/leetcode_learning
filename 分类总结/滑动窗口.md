滑动窗口题有很多，这里给一个例子和代码来总结：LC 209
```
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left = 0
        res = float('inf')
        sum_ = 0
        for right, num in enumerate(nums):
            sum_ += num
            while sum_ - nums[left] >= target:
                sum_ -= nums[left]
                left += 1
            if sum_ >= target:
                res = min(res, right-left+1)
        return res if res!=float('inf') else 0
```
基本都是一个套路，用 for 循环来扩大窗口右端，用 while 来缩小窗口直到不满足条件。每个循环都更新 res（有时候要根据情况更新，例如这个 LC 209）

当题目给的条件能够看出单调性的时候，就可以考虑是否要用滑窗。比如说题目给只有正整数的 array，求最长能满足条件（比如和大于某个值）的子串。通过滑窗可以单调递增的增加和，缩小可以单调递减的减少和。
